📊 Vrinda Sales Annual Report Dashboard (Excel)

About this project

This project focuses on building an interactive sales dashboard using Excel to analyze yearly performance of an e-commerce business.

The aim was to present business data in a clear and interactive format using filters and visualizations.

Key Insights

* Women contribute around **64% of total sales**, indicating a strong female customer base
* Adult age group generates the highest number of orders
* Amazon and Flipkart are the leading sales channels
* Maharashtra, Karnataka, and Uttar Pradesh are top-performing states
* Majority of orders (~93%) are successfully delivered

---

What I built

* Interactive filters (Month, Channel, Category)
* Sales vs Orders trend analysis
* Customer segmentation (Age & Gender)
* Channel-wise and state-wise performance analysis
* Order status breakdown

---

Tools Used

* Microsoft Excel
* Pivot Tables
* Charts & Slicers

---

What I learned

This project helped me understand how to build dashboards in Excel that are simple, interactive, and useful for business users.
